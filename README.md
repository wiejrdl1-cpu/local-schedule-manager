# 내 일정 관리하기

<img src="assets/app_icon.png" alt="내 일정 관리하기 아이콘" width="128">

공공기관 업무용 PC에서 인터넷이나 외부 서버 없이 실행하는 개인용 민원·수시업무 기한 관리 MVP입니다.

- [최신 Windows EXE 내려받기](https://github.com/wiejrdl1-cpu/local-schedule-manager/releases/latest)
- [변경 이력](CHANGELOG.md)

## 현재 구현된 기능

- 새올 민원 처리 및 수기 등록
- 사용자 정의 처리단계와 세부 분기
- 단계별 완료·현재·실행 전 상태 저장과 분기형 진행 막대
- `받은민원.xls`, `.xlsx`, `.xlsm` 가져오기 미리보기
- 접수번호 기준 신규·중복·변경·오류 판정
- 최초 처리기한과 현재 처리기한 분리
- 처리기한 연장 사유 및 변경 이력 보관
- 수시업무 등록과 자유 입력형 비고 관리
- 수시업무 사용자 정의 처리단계와 세부 분기
- 수시업무 샘플 Excel 다운로드 및 일괄 가져오기 (`YYYY-MM-DD` 예시 행 제공)
- 대한민국 공휴일이 자동 표시되는 월간 달력
- 날짜를 더블클릭해 선택형 시간과 함께 개인 일정을 등록하고 수정·삭제
- 날짜별 새올·수시업무·일정 건수, 시간 요약과 선택 항목 상세 내용 확인
- 한글 조합 중과 입력 완료 후에도 동일하게 표시되는 입력 글꼴
- D-Day, 당일, 기한 초과 자동 계산
- 오늘 마감·3일 이내·기한 초과 요약
- 성명·생년월일·접수번호 검색
- 완료 처리 및 완료 내역
- Windows 사용자 계정 기반 자동 잠금 해제와 민감정보 암호화
- 작업 내용 즉시 자동 저장
- 완료 내역은 최근 30개까지 보관
- Ctrl/Shift 다중 선택과 일괄 완료·삭제
- 휴지통 복원 및 확인 후 영구 삭제
- 선택 항목의 처리기한·진행 단계·비고 일괄 변경
- 오늘·3일 이내·이번 주·기한 초과 빠른 필터
- 민원·수시업무 변경 이력 보기
- 앱 시작 시 개인정보가 없는 Windows 알림

## 실행

PowerShell에서 다음 명령을 실행합니다.

```powershell
Set-ExecutionPolicy -Scope Process Bypass
& '.\실행.ps1'
```

현재 Codex 작업 환경처럼 사용자 경로에 한글이 포함된 경우에도 `실행.ps1`이 화면 구성 파일을 영문 임시 경로에 준비한 뒤 실행합니다.

또는 Python 3.11 이상과 의존성을 설치한 뒤 실행합니다.

```powershell
python -m pip install -r requirements.txt
python app.py
```

처음 실행하면 현재 Windows 사용자 계정에 맞춰 데이터 보호가 자동으로 설정됩니다.

## Windows EXE

GitHub Release에서 `LocalScheduleManager.exe`를 내려받으면 Python 설치 없이 실행할 수 있습니다. Windows가 처음 실행하는 파일에 대해 보호 경고를 표시할 수 있으므로, 배포 전 기관 내부 보안 기준에 따라 검사한 뒤 사용하세요.

개발자가 EXE를 다시 만들 때는 PowerShell에서 다음 명령을 실행합니다.

```powershell
& '.\빌드.ps1' -InstallDependencies
```

의존성이 이미 설치된 이후에는 다음 명령만 실행합니다.

```powershell
& '.\빌드.ps1'
```

완성 파일은 `dist\LocalScheduleManager.exe`에 생성됩니다. 배포용 EXE의 프로그램 데이터는 EXE 옆이 아니라 `%LOCALAPPDATA%\내일정관리`에 저장됩니다.

## 데이터 저장

소스코드 실행 데이터는 `%LOCALAPPDATA%\업무기한관리\schedule.db`, 배포용 EXE 데이터는 `%LOCALAPPDATA%\내일정관리\schedule.db`에 저장됩니다. 두 실행 환경을 분리하므로 새 EXE는 기존 개발용 업무를 불러오지 않고 0건에서 시작합니다. 기존 개발용 데이터는 삭제하지 않습니다.

```powershell
$env:DDAY_MANAGER_DATA_DIR = 'D:\기관내부폴더\업무기한관리'
python app.py
```

성명, 생년월일, 담당자, 메모, 업무 내용 및 연장 사유는 암호화해 저장합니다. 접수번호, 민원명, 날짜와 상태는 목록 정렬 및 기한 계산을 위해 데이터베이스에 구조화해 저장합니다.

## 엑셀 열 인식

기본 필수 열은 `접수번호`, `민원명`, `받은일자`, `처리기한`입니다. 다음 열도 자동 인식합니다.

- 처리단계
- 접수일자
- 민원인
- 접수구분
- 담당자

실제 기관 엑셀의 열 제목이 다르면 `excel_import.py`의 `ALIASES`에 별칭을 추가할 수 있습니다.

수시업무는 프로그램에서 샘플 파일을 내려받을 수 있으며, 열 제목은 `업무제목`, `등록일`, `처리기한`, `비고`입니다. 첫 데이터 행에 `YYYY-MM-DD` 날짜 형식 예시가 들어 있고 가져오기에서는 이 예시 행을 자동으로 제외합니다. 완전히 비어 있는 행은 제외하고, 각 셀의 빈 값은 빈 값 그대로 등록합니다.
